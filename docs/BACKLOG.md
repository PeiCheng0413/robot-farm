# 浮葉農場｜設計決策與待辦

最後整理：2026-10-18。已定案的項目不重開，除非使用者自己推翻。日期是定案（或推翻）的那天。

## 核心概念

玩法參考 Swift Playgrounds：學生用 Blockly 積木寫腳本控制機器人種田，學習運算思維。
田是固定的不規則形狀（像益智魔珠的零件），形狀本身就是一道走位題目。

## 已定案

**關卡：田＝形狀 × 類型**
- 形狀（直線、L、T、U…）＝關卡，只決定走位題目；類型＝難度，只決定輔助規則（`config.js` 的 `PLOT_TYPES`）。
- 四種難度，一級拿掉一項輔助，越難能種越高級的作物：新手（不扣 Token、系統自動選播種／採收腳本、土壤不會乾，1 級作物）→ 進階（開始扣 Token，2 級）→ 高級（土壤會乾，多一份澆水腳本，3 級）→ 專家（一份腳本全部自己判斷，含「沒事做就離開」，4 級）。
- 類型買下後固定，不能升級；想換就賣掉再買。
- **同關卡同難度的田共用一份腳本、積木上限與星等**（`state.levels`），解一次就好；賣田時腳本與星等留在關卡裡（10-16，推翻「賣田時腳本一起消失」）。理由：重複寫一樣的程式對運算思維沒有意義。
- 星等：一星＝試跑通過過關檢查；二星＝積木數 ≤ 目標（`STAR_TARGETS`，暫定估算）；三星＝再加上沒有白做、沒有撞牆。只在該腳本的預設情境下記分；關卡星等取各份腳本最低值。
- 選關畫面就是商店：每關列出四種難度的星等、擁有數量、價格。

**盤面、買賣、擴地**
- 盤面 12 × 7 格；開局只開放中間 5 × 3，送一塊直線新手田（之後改成新手教學的獎勵）。
- 擴地一格一格買，只能買上下左右緊鄰已開放的格子，越買越貴（`LAND_PRICE`）。
- 買田：價格＝形狀底價 × 類型倍數，買下先進倉庫；排列模式從倉庫拖到盤面，也能拖回倉庫。倉庫裡的田不生長、機器人不去。
- 賣田：退回一半買價，田與作物消失。盤面上至少要留一塊田。
- 排列：可旋轉 90°、不可翻面（旋轉後腳本照樣能用，翻面會左右對調），拖曳吸附格子。只受空間限制，不影響腳本，相鄰田不連通。

**腳本與執行**
- 動作：前進、左轉、右轉（相對方向）、播種、澆水、採收；之後擴充跨越障礙、除草、除蟲、施肥。積木與田格狀態做成「新增一筆定義就能用」。
- 自動選腳本的難度：採收 > 播種 > 澆水，上一輪跑過的往後排（避免某份腳本霸佔）；澆水只看還在長、而且乾裂的作物。
- 條件有「且」「或」「不是」。「這塊田…」檢查整塊田任一格，「腳下…」只檢查所在那格。
- 函式：每份腳本各自定義，定義與內容計入積木數，呼叫不扣 Token，暫不支援參數。
- 執行不用 Blockly：積木編譯成 JSON 指令樹，由逐步直譯器執行；排程是確定性的。
- 撞到邊界：原地不動、照樣扣 Token，不當機。

**Token 與金錢**
- Token 是全農場共用總額，金錢可兌換 Token。
- 只有前進、播種、澆水、採收扣 Token；轉彎、重複、如果、感測、離開都不扣（10-15）。
- 每份腳本有積木數上限，可花錢擴充。新手田永遠不扣 Token，當作保底收入。
- 執行到一半 Token 用完 → 那塊田當機、卡住機器人，手動免費重置，作物與土壤保留。學生要自己寫「Token 少於 N 就離開」防呆。
- 沒事做就白走扣 Token，是要學生學會寫守門，不用冷卻時間替學生擋掉。

**畫面**
- 主畫面 `play.html`：斜角山谷場景（`scene.js`，依 manifest `valleyScene` 把地面轉 18°、壓 0.625，直立物不轉）。不畫田地名牌、不畫土壁厚度（10-17）。滑鼠移到田上發光並在游標旁顯示田名與狀態，點下去打開田地卡片。
- 排列田地時切成俯瞰（依 `farmWorld.views.topDown` 的俯瞰地圖），不畫機器人（沒有俯視素材）。兩個視角共用 `state.layout`。
- 樹只種在俯瞰地圖的林帶範圍內，落地點高於遠景交界線的不畫；前景框邊樹叢壓暗約三成。
- 腳本編輯畫面：左邊積木、右邊田的特寫；沙盒試跑（不扣真的 Token）、每個積木都停的逐步執行、試跑情境、過關檢查。
- 機制測試畫面 `game.html`：正上方盤面、加速、給錢，開發測試用。與主畫面共用存檔。
- 有載入畫面；主畫面只下載斜角場景要用的圖（約 4.5MB，manifest 另計），不下載名牌、舊溫室與第一版山谷的大圖；測試畫面反過來不下載場景圖。
- 當機：機器人循環播當機動作、頭上紅叉泡泡，「！當機」標籤放腳下並畫在最上層（10-18）。

**上課練習頁 `practice.html`（10-18）**
- 跟農場完全獨立：不扣 Token、不賺錢、不共用存檔；進度（星等與每關積木）存在該台瀏覽器，積木隨改隨存。
- 關卡寫成數據表 `game/lessons.js`（田的樣子用字元地圖、出發點、目標、這關的積木箱、星等門檻、老師參考解）。
- 做完目標就過關（一星）；二星、三星看積木數，三星還要沒撞牆、沒白做。關卡全部開放，網址 `#lesson=3` 直接開第三關。
- 第一組四關（10-18 使用者調整）：一排幼苗 → 先播種再澆水 → 看一看再澆水（「如果 腳下土壤乾裂」，練判斷）→ 繞一圈（重複包重複）。每關只給需要的積木。原本的「轉個彎」「來回兩排」取消。

**分工與技術**
- 素材、素材試驗室、動畫數據歸 ChatGPT；遊戲本體歸 Claude；唯一接點是 `manifest.json` 與 `alignment.js`（見 `AGENTS.md`）。
- Blockly 12.5.1 放在 `vendor/`，不走 CDN；零 node 依賴；localStorage 存檔（版本 4）。

## 程式架構（`game/`）

- `config.js` 數值表 ／ `plots.js` 形狀、旋轉與擺放 ／ `sim.js` 模擬、排程、經濟、關卡（事件格式寫在檔頭）
- `interpreter.js` 逐步直譯器 ／ `blocks.js` Blockly 積木與編譯 ／ `session.js` 存檔
- `render.js` 素材載入、繪圖元件、測試畫面盤面、田特寫 ／ `scene.js` 主畫面斜角與俯瞰
- `editor.js` 腳本編輯畫面 ／ `play.js` 主畫面 ／ `main.js` 機制測試畫面
- `practice.js` 上課練習頁 ／ `lessons.js` 練習關卡數據
